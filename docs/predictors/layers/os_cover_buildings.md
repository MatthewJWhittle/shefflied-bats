# Building cover (`os_cover_buildings`)

Share of each model cell covered by OS VMD **buildings** features.

## Source and licence

OS Vector Map District (OGL). See [os_vector_map_district](../sources/os_vector_map_district.md).

## Pipeline

`os` rebuild step → `os-feature-cover.tif` → merge as `os_cover_buildings`.

## Role

**Data** — OS cover predictor.
