# Improved grassland cover (`ceh_landcover_improved_grassland`)

In-cell share of UKCEH LCM 2023 class Improved grassland (code 4) on the model grid (percent × 100).

## Source and licence

## Pipeline

`ceh` rebuild step → merge as `ceh_landcover_improved_grassland`.
