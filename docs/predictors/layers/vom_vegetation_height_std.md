# Vegetation canopy height — std (`vom_vegetation_height_std`)

Within-cell standard deviation of EA **VOM** canopy-top height (m).

## What it shows / does not show

Variability of top-of-canopy height inside the cell (edges, mixed canopy). Not
vegetation under 2.5 m, understorey layering, or leaf-on hedge detail.

## Source

Same product as [`vom_vegetation_height_mean`](vom_vegetation_height_mean.md).
Official page: [LIDAR Vegetation Object Model (VOM)](https://www.data.gov.uk/dataset/227ab487-e8f2-4cbb-b26a-9e6d3b662265/lidar-vegetation-object-model-vom)
— canopy-top height for objects **above 2.5 m**; National LiDAR flown **leaf-off**.

## Role

**Data** — vegetation structure predictor.
