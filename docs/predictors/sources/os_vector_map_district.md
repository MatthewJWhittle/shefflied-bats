# OS Vector Map District (`os_vector_map_district`)

Ordnance Survey open vector product behind `os_cover_*` and `os_distance_*`
predictors.

## Provider and product

**Ordnance Survey** — Vector Map District (buildings, water, roads themes).

## Licence and access

[Open Government Licence v3.0](https://www.nationalarchives.gov.uk/doc/open-government-licence/version/3/).
Downloads:
[OS Data Hub — Vector Map District](https://osdatahub.os.uk/downloads/open/VectorMapDistrict).

## Citation

Contains OS data © Crown copyright and database right.

## Notes

Layer docs state which theme (buildings, water, major/minor roads) each band
uses. Cover bands are in-cell fractions; distance bands are metres to the
nearest feature on the model grid.
