# OS Boundary-Line (`os_boundary_line`)

Coastline / mean high water geometry used for distance-to-coast.

## Provider and product

**Ordnance Survey** — Boundary-Line (mean high water / coastline polylines by
default).

## Licence and access

[Open Government Licence v3.0](https://www.nationalarchives.gov.uk/doc/open-government-licence/version/3/).
Downloads:
[OS Data Hub — Boundary-Line](https://osdatahub.os.uk/downloads/open/BoundaryLine).

## Citation

Contains OS data © Crown copyright and database right.

## Notes

Optional legacy BGS GeoCoast polygons remain available for like-for-like
rebuilds. The model band id keeps the historical `bgs_coast_` prefix.
