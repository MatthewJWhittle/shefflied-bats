# EA LIDAR Vegetation Object Model (`ea_vom`)

Vegetation / canopy height product behind `vom_vegetation_height_*` predictors.

## Provider and product

**Environment Agency** — LIDAR Vegetation Object Model (VOM).

## Notes

Heights below about 2.5 m are weak for canopy interpretation. Leaf-off surveys
understate deciduous canopy. Layer docs cover mean / max / std and neighbourhood
derivatives.
